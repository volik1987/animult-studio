# АниМульт Студия

Приложение для создания своих аниме-мультиков (PWA, работает на телефоне и без интернета).

1. **Персонажи** — редактор в духе Gacha: лицо, глаза, брови, рот, причёски, одежда, обувь, аксессуары, цвета. Любую деталь можно сдвинуть перетаскиванием или стрелками, увеличить и повернуть.
2. **Студия** — 16 локаций или своё фото фоном, персонажи, предметы, пузыри с текстом. Позу собираешь сам, сгибая суставы на сцене. Кнопка 📸 сохраняет кадр.
3. **Монтаж** — кадры собираются в покадровый ролик, к нему добавляются звуки, музыка, свой голос и свои файлы. Экспорт в MP4 или WebM.

Обновление офлайн-кэша: `python3 make-sw.py` перед каждым коммитом.
